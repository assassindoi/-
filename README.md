# tone. — ボイトレの練習管理

声を育てる毎日の習慣をまとめる、React + Vite のアプリです。

## Windows で起動

Node.js LTS をインストールしたあと、`Start-tone.cmd` をダブルクリックすると依存関係の準備とアプリの起動を行い、ブラウザを開きます。使用中は黒い画面を開いたままにしてください。以前起動した tone. の黒い画面が残っている場合は先に閉じてください。

更新時は ZIP を展開し、元のアプリフォルダ内のファイルを最新版で置き換えてから起動します。同じブラウザで `http://localhost:5173/` を使い続ければ保存済みの音声・記録を参照できます。ブラウザのデータは削除しないでください。

## 起動

Node.js 22 以上を使用します。

```sh
npm ci --cache /tmp/tone-npm-cache
npm run dev -- --port 5173
```

```sh
npm test
npm run build
```

## できること

- 練習メニューの追加・編集・削除、曜日・開始時刻・練習時間の指定
- タイマー、練習完了、5段階の手応え・気づきの記録
- 直近7日間の練習時間、累計回数・時間、練習履歴
- 参考音声のアップロード・保存・再生・リピート・シーク
- 参考音声のドラッグ操作による並び替えと順番の自動保存（練習中の選択欄にも反映）
- 音声ごとの発声時の注意点メモ（クリックで開閉、編集・自動保存、練習中にも参照）
- Web Audio API による参考音声とマイク入力のリアルタイム周波数スペクトラム
- 課題・気づき・成長方針・パートナーのアドバイスをまとめるノート
- 筋トレマップの課題・達成状態の編集と練習メニューへの紐づけ
- Miro ボードの URL を保存して元のマップを開く
- 練習記録・メニュー・課題・ノートの JSON 書き出し（音声は含まない）

## 保存と制限

データは同じブラウザ・同じオリジンの localStorage、音声は IndexedDB に保存します。サーバーへのアップロードは行いません。ブラウザデータを消すと失われるため、必要に応じて記録ページから書き出してください。音声の原本は別に保持してください。端末間同期、共同編集、JSON の再取り込みは未実装です。

Miro はボードリンクの参照に対応します。ボードの読み取り・自動同期は行いません。初期のメニューとマップは編集できるサンプルです。マップ達成状態は手動で設定します。

開始時刻は目安の表示です。プッシュ通知やバックグラウンドのリマインダーはありません。タイマーはページを開いている間の練習用で、バックグラウンドではブラウザにより遅延する場合があります。完了時にはメニューで設定した分数を記録します。

マイクは localhost または HTTPS 上で、ブラウザの許可が必要です。音声形式の再生可否はブラウザに依存します。スペクトラムは音響の確認用で、歌唱力を自動採点する機能ではありません。

## ブラウザでの動作テスト

開発サーバーを起動した状態で、Chromium が `/usr/bin/chromium` にある環境では以下を実行できます。

```sh
npm run test:e2e
```

メニュー作成、タイマー、記録、ノート、Miro リンク、保存の永続性、音声のアップロード・再生・スペクトラム・リピート、模擬マイク、スマホ幅での横はみ出しを検証します。実マイクの音質・入力デバイスは検証対象外です。`APP_URL` で接続先を変更できます。
